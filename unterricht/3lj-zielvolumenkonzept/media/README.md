# Zielvolumenkonzept – 3. Lehrjahr

Dieser Ordner enthält die einfache Videoansicht und die sechs zugehörigen MP4-Dateien. Die Unterrichtsmaterialien M1 und M3–M5 bleiben separat. Einstieg: `unterricht/3lj-zielvolumenkonzept/index.html`.

Die Videodateien sind für die Wiedergabe im Browser als H.264/AAC MP4 aufbereitet.

Zum Abschalten GitHub Pages unter **Settings → Pages → Unpublish site** deaktivieren. Zum Entfernen den gesamten Ordner `unterricht/3lj-zielvolumenkonzept/` löschen. Öffentlich gewesene Dateien können weiterhin in der Git-Historie, in Forks oder in bereits angefertigten Kopien existieren. Die Playeroption `nodownload` entfernt lediglich die gewöhnliche Download-Schaltfläche.
